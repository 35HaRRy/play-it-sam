# play-it-sam

## Summary
A LangChain-based Spotify assistant that plans and executes actions against the Spotify API.

## Dependencies
- Python
- `langchain-core`
- `langchain-community`
- `langgraph`
- `langchain-groq`
- `spotipy`
- `PyYAML`
- `python-dotenv`

## Setup
1. Create and activate a virtual environment.
2. Install the Python dependencies listed above.
3. Add your Spotify and Groq credentials to a `.env` file.
4. Run `python start.py` to launch the assistant, or open the notebooks for experimentation.
